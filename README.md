# Synthetic Thermal-Comfort Sequence Generation

The current experiment is implemented through several groups of code. `temporal_utils.py` handles session loading, numeric frame sorting, and the four selected features, while `preprocess_indoor_every10.py` keeps every tenth raw observation and constructs 30-step sequences within each session. `train_generate_sdv_every10.py` trains TVAE and CTGAN and generates their synthetic datasets. `generate_direct_prompt_ablations.py` implements Direct-Naive and Direct-Controlled, in which DeepSeek directly outputs complete 30-by-4 sequences. `generate_sparse_prompt_ablations.py` implements Sparse-Naive and Sparse-Controlled, in which DeepSeek outputs a base state and a small number of change events. `eval_paper_lstm_2x2.py` uses the paper-aligned LSTM, 84,000 optimizer updates, and five random seeds to calculate Synthetic-to-Real performance. `audit_every10_generation.py` checks the validity of all synthetic data, `audit_direct_prompt_ablations.py` examines temporal changes, duplication, and memorization in the dense methods, and `audit_sparse_prompt_2x2.py` evaluates the complete Dense/Sparse by Naive/Controlled ablation.
